## B. Information that is deliberately **not published**
1. Opening hours (hospital, per department, per diagnostic service) — Admin → Settings (tick *confirmed*).
2. Whether emergency services are available and when — never claimed; Admin → Settings → Emergency status.
3. Doctors: names, qualifications, registration numbers, experience, languages, photographs, schedules, fees — add under Admin → Doctors; publish only after verifying credentials.
4. Google Maps location/link — verify then enter in Settings and tick *verified*.
5. Founding year, registrations/licences, accreditation, awards, statistics, reviews — not included anywhere.
6. Charitable Trust details beyond the name (history, trustees, activities).
7. Email address (optional), real photographs (hero image URL) and the official logo files.
8. Consultation fees (shown only if “approved for display” per doctor).
9. Preparation instructions per diagnostic service (shown only if “approved by clinical staff”).
10. Holidays and temporary closures — Admin → Holidays.
